¿Qué es un script de Bash?

Es un archivo de texto que contiene comandos para que Bash los ejecute en orden. Sirve para automatizar tareas, procesar archivos y combinar programas de la terminal.

1. Tu primer script

Crea un archivo llamado hola.sh:

#!/usr/bin/env bash

echo "Hola, mundo"

Ejecútalo con:

bash hola.sh

También puedes hacerlo ejecutable:

chmod +x hola.sh
./hola.sh

La primera línea, llamada shebang, indica qué intérprete debería ejecutar el archivo.

2. Variables y argumentos

Las variables guardan valores. No pongas espacios alrededor de =:

nombre="Ada"
echo "Hola, $nombre"

Los argumentos se reciben como $1, $2, etc.:

#!/usr/bin/env bash

nombre="${1:-mundo}"
echo "Hola, $nombre"

Al ejecutar bash saludo.sh Marta, el script saludará a Marta.

  • $1, $2: primer y segundo argumento.
  • $#: cantidad de argumentos.
  • "$@": todos los argumentos, conservando cada uno por separado.
  • $0: nombre o ruta del script.

Usa comillas en las variables, especialmente cuando contienen rutas: "$nombre".

3. Condiciones y comprobación de archivos

#!/usr/bin/env bash

if [[ $# -ne 1 ]]; then
  echo "Uso: $0 ARCHIVO" >&2
  exit 1
fi

archivo="$1"

if [[ ! -f "$archivo" ]]; then
  echo "No se encuentra el archivo: $archivo" >&2
  exit 1
fi

echo "Archivo válido: $archivo"

Pruebas comunes dentro de [[ ... ]]:

  • -f "$ruta": existe y es un archivo normal.
  • -d "$ruta": existe y es una carpeta.
  • -e "$ruta": existe.
  • -z "$texto": el texto está vacío.
  • "$a" == "$b": dos cadenas son iguales.

Para comparar números, puedes usar (( ... )):

edad="$1"

if (( edad >= 18 )); then
  echo "Mayor de edad"
else
  echo "Menor de edad"
fi

4. Bucles

Recorrer los argumentos

for argumento in "$@"; do
  echo "Argumento: $argumento"
done

Recorrer archivos de una carpeta

for archivo in ./*.txt; do
  [[ -e "$archivo" ]] || continue
  echo "Encontrado: $archivo"
done

Repetir una acción

contador=1

while (( contador <= 5 )); do
  echo "$contador"
  ((contador++))
done

5. Funciones

Las funciones agrupan código para poder reutilizarlo:

saludar() {
  local nombre="$1"
  echo "Hola, $nombre"
}

saludar "Rita"

local limita una variable a esa función. Los argumentos de la función se reciben como $1, $2, etc.

6. Entrada y salida

Pedir un dato por teclado:

read -r -p "¿Cómo te llamas? " nombre
echo "Hola, $nombre"

Guardar en una variable la salida de un comando:

fecha=$(date +%F)
echo "Hoy es $fecha"

Guardar texto en archivos:

echo "inicio del proceso" > registro.txt
echo "siguiente línea" >> registro.txt
  • > crea o sobrescribe un archivo.
  • >> añade contenido al final.
  • | pasa la salida de un comando a otro.
grep -i "error" registro.txt | sort

7. Errores y salida del script

Por convención, exit 0 indica que el script terminó correctamente. Un número distinto de cero suele indicar un error. echo ... >&2 muestra un mensaje en la salida de error. 

#!/usr/bin/env bash
set -euo pipefail

uso() {
  echo "Uso: $0 ARCHIVO" >&2
}

if [[ $# -ne 1 ]]; then
  uso
  exit 1
fi

archivo="$1"

if [[ ! -f "$archivo" ]]; then
  echo "No es un archivo válido: $archivo" >&2
  exit 1
fi

echo "Procesando $archivo"

set -euo pipefail ayuda a detectar algunos errores, pero no reemplaza las comprobaciones explícitas.

8. Ejercicio: contar líneas

Crea contar.sh para contar las líneas de un archivo:

#!/usr/bin/env bash

if [[ $# -ne 1 || ! -f "$1" ]]; then
  echo "Uso: $0 ARCHIVO" >&2
  exit 1
fi

wc -l < "$1"

Prueba el script:

chmod +x contar.sh
./contar.sh notas.txt

Más ejercicios

  1. Modifica el script para aceptar varios archivos.
  2. Haz un script que indique si una ruta es archivo o carpeta.
  3. Recorre los archivos .log de una carpeta.
  4. Crea una función que imprima un mensaje de bienvenida.
Buenas prácticas:
  • Pon entre comillas las variables usadas como rutas: "$archivo".
  • Usa nombres de variables descriptivos.
  • Prueba con archivos de ejemplo antes de procesar datos importantes.
  • Ten cuidado con comandos de borrado y revisa las rutas antes de ejecutarlos.
