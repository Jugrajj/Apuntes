Bash scripting para principiantes

Aprende a crear pequeños programas que ejecutan comandos automáticamente en una terminal.

¿Qué es Bash?

Bash es un intérprete de comandos habitual en Linux y macOS. Un script de Bash es un archivo de texto con comandos que Bash ejecuta en orden. Sirve para automatizar tareas repetitivas, como organizar archivos o crear copias de seguridad.

Tu primer script

Crea un archivo llamado saludo.sh con este contenido:

#!/usr/bin/env bash
echo "¡Hola! Este es mi primer script."

La primera línea indica que el script debe ejecutarse con Bash. Para ejecutarlo:

chmod +x saludo.sh
./saludo.sh

También puedes ejecutarlo directamente con bash saludo.sh.

Variables

Una variable guarda un valor. No pongas espacios alrededor de =:

nombre="Ana"
echo "Hola, $nombre"

Usa comillas alrededor de las variables para manejar mejor los espacios:

archivo="mis documentos.txt"
echo "$archivo"

Leer información

read espera a que la persona escriba una respuesta:

#!/usr/bin/env bash

echo "¿Cómo te llamas?"
read -r nombre
echo "¡Hola, $nombre!"

La opción -r evita que Bash interprete las barras invertidas como caracteres especiales.

Condiciones

Con if puedes ejecutar acciones distintas según una condición:

#!/usr/bin/env bash

read -r -p "Escribe un número: " numero

if [ "$numero" -gt 10 ]; then
  echo "Es mayor que 10."
else
  echo "Es 10 o menor."
fi

-gt significa “mayor que”. Para números también puedes usar -lt (menor que) y -eq (igual a).

Bucles

Un bucle for repite instrucciones para cada elemento:

for fruta in manzana pera naranja; do
  echo "Fruta: $fruta"
done

Funciones

Una función reúne comandos para poder reutilizarlos:

saludar() {
  echo "¡Hola, $1!"
}

saludar "Luis"

$1 representa el primer argumento recibido por la función.

Consejos básicos

  • Usa nombres claros para los archivos y las variables.
  • Pon las variables entre comillas, por ejemplo: "$nombre".
  • Prueba el script con datos simples antes de usarlo en archivos importantes.
  • Para mostrar los comandos mientras se ejecutan, puedes usar bash -x script.sh.

Algunos comandos pueden borrar o cambiar archivos. Revisa cada línea antes de ejecutar un script que hayas encontrado o descargado.
